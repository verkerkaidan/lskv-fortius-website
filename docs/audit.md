# LSKV Fortius – audit (2026-10-06)

Source: live pages, Site Editor export, `custom.css`, content XML. Baseline screenshots: `baseline/live/` (5 pages × desktop/mobile, regenerate with `node tools/screenshot.mjs <base-url> <outdir>`).

## Constraints (WordPress.com Personal)
- No custom theme / plugin upload, no staging, no git deploy.
- Deliverables must be importable through the editor: Global Styles, patterns (JSON), template/part markup, Additional CSS.
- Host strips CSS custom properties (`--x:`) from Additional CSS. `var(--wp--preset--*)` generated by Global Styles still works, so tokens belong in Global Styles, not CSS.

## Findings
| Area | Finding |
|---|---|
| Additional CSS | 1,749 lines, 318 `!important`, no variables, every colour written out literally |
| Palettes | Three competing: Global Styles palette (#1B1B1B, #F0F0F0, #800000, #e00000…), CSS (#121212, #c81e2c, #3a3a38, #eceae6, #8a8a86, #8f1520) and header/footer (#0d0d0f, #c8102e, #c9c9ce, #26262b) |
| Font sizes | Mix of px, rem, clamp and presets; ~20 distinct values in CSS |
| Fonts | Titan One (headings) and Archivo (body), forced with `!important` in 29 rules instead of Global Styles typography |
| Header/footer | Colours, spacing and borders hardcoded in block attributes, not tied to the palette |
| Class mismatches | Used in content but no CSS: `fortius-archive-query`, `fortius-more-posts-item`, `fortius-post-list`, `fortius-post-nav-wrap`, `fortius-word-lid-btn`, `quote-card-body`, `quote-strip-wrap`. Defined in CSS but unused in content: `fortius-card`, `fortius-card-arrow`, `fortius-form-embed`, `fortius-form-placeholder`, `fortius-post-nav`, `fortius-post-tags`, `fortius-section-instagram`. |
| Stray classes | `ai-ignore`, `ai-show-if-*`, `md:order-0`, `order-1`, `is-clone` (leftovers from pasted/AI-generated markup) |
| Naming | Mixed `fortius-*`, bare (`kicker`, `quote-card`, `section-cta`) and `samenwerkingen-*` (Dutch) |
| Content | 7 pages, 1 post, 9 patterns, 8 templates, 3 parts, 1 navigation; 260 group blocks, only 2 `wp:html` |

## Plan
1. Baseline screenshots (done).
2. Tokens as Global Styles + theme-level typography/button styles; strip the `!important` overrides.
3. Group CSS by component; delete dead rules; one naming scheme (`fortius-<component>`, English).
4. Rebuild repeated sections as patterns (hero first), headers/footers as template parts.
5. Local WordPress Studio copy, compare against `baseline/live/`, then apply to live in one go.

## Status (end of cleanup)
- Additional CSS: 1,749 -> ~1,590 lines, `!important` 318 -> 58. The rest override WordPress core/Jetpack output (mobile nav overlay, comment form, pagination, post navigation, instagram grid, block font-size presets) or inline mobile padding; they cannot be moved into markup.
- Side padding of sections is one rule (the "horizontal inset" block); blocks no longer carry their own left/right padding.
- Accepted visual differences vs live: paragraph colour in Style 3/5 sections #121212 -> #3a3a38, uniform annotation spacing, Outline button transparent with 2px border, header border #c8102e -> #c81e2c.
